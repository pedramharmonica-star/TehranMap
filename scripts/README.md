# اسکریپت‌ها

همه‌ی اسکریپت‌ها پوشه‌ی کاری را از `TEHRANMAP_WORK` می‌خوانند (پیش‌فرض `./work`). آن را با `bash tools/setup_work.sh` بسازید. پایتون را با `python3 -I` اجرا کنید.

| پوشه | اسکریپت | کار |
|---|---|---|
| `v1-initial` | `prep.py` | شیپ‌فایل مناطق → WGS84، اجتماع شهر، برش Natural Earth (آزمایشی) |
| | `georef.py` | تطبیق اسکرین‌شات گوگل‌مپ با برچسب شهرها (۳ پارامتر Mercator) |
| | `overlay.py` | کشیدن مرز مناطق روی اسکرین‌شات برای بررسی تطبیق |
| | `blue.py` | استخراج خط آبی بسته و flood fill چندبذری → ماسک محدوده |
| | `build_geo.py` | ماسک → چندضلعی، صاف کردن (open/close و Chaikin)، اجتماع با شهر، `geo.json` |
| | `places.py` | تعیین لایه‌ی شهرهای اطراف |
| | `assemble.py` | ساخت صفحه‌ی نسخه‌ی ۱ از `template-v1.html` |
| `v2-v4-basemap` | `osm_extract.py` | pbf → `base.json` و `minor.json` (جاده‌ها در ۸ کلاس، آب، سبز، راه‌آهن، اسم محله‌ها) |
| | `logo.py` | وکتور کردن لوگو با potrace (`~mask`) |
| | `glass.py` | تبدیل باکس‌ها به شیشه‌ای و درج لوگو در template (یک‌بار مصرف، برای سابقه) |
| `v5-redraw` | `v5_georef.py` | تطبیق اسکرین‌شات نقشه‌ی خودمان با اسم شهرها |
| | `v5_blue.py` | اسکلت خط باز → مسیر مرتب بین دو انتهای دور |
| | `v5_build.py` | صاف کردن، چسباندن به جاده‌های اصلی و مرز مناطق، بستن با کمان قبلی |
| | `v5_check.py` | تصویر مقایسه‌ی خط دستی و مرز ساخته‌شده |
| | `v5_apply.py` | نوشتن مرز در `geo.json` و محاسبه‌ی دوباره‌ی لایه‌ی شهرها |
| `build` | `port.py` | template → `app/src` (mapEngine.ts، map.css، App.tsx) |
| | `finalize.py` | bundle → صفحه‌ی نهایی با فونت و داده‌ی جاسازی‌شده |
| `screenshots` | `shot*.js` | اسکرین‌شات با Playwright در دسکتاپ و موبایل |
